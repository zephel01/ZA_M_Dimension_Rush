# Pokemon Legends: Z-A M次元ラッシュ自動化スクリプト

Pokemon Legends: Z-A の「M次元ラッシュ」を周回・厳選するための自動化スクリプトです。
Poke-Controller Modified Extension（PCME）の Python コマンドとして動作します。

**Version:** 3.2

## 概要

ゲーム内の移動を自動化し、M次元ラッシュの周回を支援します。4つの移動モードがあり、状況に応じて使い分けられます。

v3.2 から、**Start を押すと開始前の設定画面が開き**、モードと数値をその場で選べるようになりました。選んだ設定は `config.json` に保存できます。

## 移動モード

| モード (`move_mode`) | 名称 | 説明 |
| :-- | :-- | :-- |
| **Type1** (0) | ホロエレベーター往復 | エレベーターで移動し、上下に歩いてから戻る動作を繰り返します。 |
| **Type2** (1) | エレベーター移動のみ | エレベーターのボタンを押して移動するだけの動作です。 |
| **Type3** (2) | シャトルラン | 指定時間、上下に往復移動します。Bダッシュを併用できます。 |
| **Type4** (3) | Fastpass | **【推奨】** ファストパスで特定地点への高速移動を繰り返します。 |

## 導入方法

1. このフォルダ（`ZA_M_Dimension_Rush.py` と `config.json`）を PCME の `Commands/PythonCommands/` の中に配置します。
2. PCME を起動し、コマンド一覧から `ZA M次元ラッシュ v3.3.0` を選びます。
3. **Start** を押すと設定画面が開きます。モードと数値を決めて **開始** を押してください。

```
Poke-Controller-Modified-Extension/
└── SerialController/
    └── Commands/
        └── PythonCommands/
            └── ZA_M_Dimension_Rush/
                ├── ZA_M_Dimension_Rush.py
                ├── config.json
                └── README.md
```

## 開始前の設定画面（v3.2）

| 部分 | 内容 |
| :-- | :-- |
| 移動モード | Type1〜Type4 を選びます。 |
| モードの設定 | **選んだモードで使う項目だけ**が表示されます。他のモードの値は消えずに残り、まとめて保存されます。 |
| 共通 | ループ回数の上限 |
| この画面 | 次回から画面を出すかどうか、操作がないとき自動で開始するまでの秒数 |
| config.json に保存する | チェックを入れて開始すると、画面の値を `config.json` に書き込みます（初期状態でオン）。外すと、その回だけ画面の値で動きます。 |

- **キャンセル**・Esc・ウィンドウを閉じる：開始しません。
- **自動で開始**：何も操作しないまま `settings_ui_timeout_seconds` 秒たつと、表示中の設定で開始します（予約やモニターから開始したときのため）。画面を一度でも操作するとカウントダウンは止まります。
- 数字以外や範囲外の値を入れると、開始時にメッセージが出て、画面に戻ります。
- **画面が出ない場合**：Web ブラウザ版の UI や実行リストから開始したとき、または `show_settings_ui` が `false` のときは、画面を出さずに `config.json` の値で開始します。

## 設定項目（config.json）

`config.json` は `ZA_M_Dimension_Rush.py` と同じフォルダに置きます。ファイルが無い場合や項目が足りない場合は、下の初期値で動きます。

| キー | 初期値 | 範囲 | 使うモード | 内容 |
| :-- | :-- | :-- | :-- | :-- |
| `move_mode` | `3` | 0〜3 | 共通 | 0=Type1 / 1=Type2 / 2=Type3 / 3=Type4 |
| `max_loop` | `9999` | 1〜999999 | 共通 | ループ回数の上限 |
| `wait_time` | `0.2` | 0.0〜60.0 秒 | Type1, Type2 | エレベーターで A を押した後の待機時間 |
| `elevator_move_time` | `2.5` | 0.1〜10.0 秒 | Type1 | 上・下それぞれに歩く時間 |
| `duration` | `3.2` | 0.1〜30.0 秒 | Type3 | 片道の移動時間 |
| `use_dash` | `true` | true / false | Type3 | Bダッシュを使う |
| `dash_delay` | `0.05` | 0.0〜5.0 秒 | Type3 | 歩き出してから B を押すまでの遅延（`duration` 以下にする） |
| `shuttle_turn_wait` | `0.5` | 0.0〜10.0 秒 | Type3 | 上下を切り替える間の待機 |
| `fastpass_wait` | `2.2` | 0.0〜30.0 秒 | Type4 | Fastpass 使用後の待機（ロード完了まで） |
| `fastpass_first_y` | `false` | true / false | Type4 | 1回目だけ最初に Y を押す（マップ画面の初期化用） |
| `show_settings_ui` | `true` | true / false | — | Start を押したときに設定画面を出す |
| `settings_ui_timeout_seconds` | `60` | 0〜3600 秒 | — | 画面で操作がないとき自動で開始するまでの秒数（0 = 自動で開始しない） |

### 書き方の注意

- JSON にはコメントを書けません。最後の項目の後ろにカンマを付けないでください。
- 真偽値は `true` / `false`（小文字）で書きます。
- 範囲外の値や数字以外の値は、起動時に警告を出してその項目だけ初期値に戻します。
- JSON の書き方が間違っている場合は、全項目が初期値になります（起動ログに `[Warning] config.json を読めませんでした` と出ます）。
- 知らないキーは無視されますが、保存しても消えません。

### 設定例

**Fastpass（推奨）、ロードが遅い環境向け**

```json
{
  "move_mode": 3,
  "fastpass_wait": 3.0,
  "fastpass_first_y": true
}
```

**シャトルラン、ダッシュなしで長めに往復**

```json
{
  "move_mode": 2,
  "use_dash": false,
  "duration": 4.5,
  "shuttle_turn_wait": 0.8
}
```

**設定画面を出さずに、すぐ開始する**

```json
{
  "show_settings_ui": false
}
```

## 旧方式（set_params）

`set_params()` は互換のために残しています。旧キー（`mode`, `wait`）と新しいキーのどちらでも渡せます。渡さなかった項目は今の設定のままです。
