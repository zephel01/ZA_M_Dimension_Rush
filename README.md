# Pokemon Legends: Z-A M次元ラッシュ自動化スクリプト

Pokemon Legends: Z-A における「M次元ラッシュ」を効率的に周回・厳選するための自動化スクリプトです。
PythonCommand（Poke-Controller等）の基盤で動作することを想定しています。

## 概要

このスクリプトは、ゲーム内での移動を自動化し、M次元ラッシュの発生や周回を支援します。4つの異なる移動モードを搭載しており、状況に応じた効率的な自動化が可能です。

## 主な機能（移動モード）

| モード (move_mode) | 名称                 | 説明                                                                            |
| :----------------- | :------------------- | :------------------------------------------------------------------------------ |
| **Type1** (0)      | ホロエレベーター往復 | エレベーターで上下に移動し、元の位置に戻る動作を繰り返します。                  |
| **Type2** (1)      | エレベーター移動のみ | エレベーターのボタンを押して移動するだけの単発動作です。                        |
| **Type3** (2)      | シャトルラン         | 指定時間、上下に往復移動を行います。Bダッシュの併用が可能です。                 |
| **Type4** (3)      | Fastpass             | **【推奨】** ファストパスを使用してマップ上の特定地点へ高速移動を繰り返します。 |

## 設定パラメータ

GUIまたはスクリプト内の `set_params` で以下の設定を変更できます。

- **共通**
  - `mode`: 移動モードの選択 (0～3)
- **Type1 / 2 用**
  - `wait`: エレベーター移動後の待機時間 (秒)
- **Type3 (シャトルラン) 用**
  - `duration`: 片道の移動時間 (秒)
  - `use_dash`: Bダッシュを使用するかどうか
  - `dash_delay`: Bボタンを押すまでのディレイ
- **Type4 (Fastpass) 用**
  - `fastpass_wait`: ファストパス使用後のロード完了待機時間 (秒)
  - `fastpass_first_y`: 初回実行時にのみYボタンを押すオプション（マップ画面の初期化用）

## 導入方法

1.  `ZA_M_Dimension_Rush.py` を `Commands` フォルダ内に配置します。
2.  PythonCommand 対応のコントローラー操作ツール（Poke-Controller等）を起動します。
3.  一覧から `ZA_M_Dimension_Rush_v3.1` を選択します。
4.  目的に応じたパラメータを設定し、スクリプトを実行してください。

## 動作イメージ

スクリプト実行中は、現在の実行回数や経過時間がログに表示されます。
例: `[12:34:56 | 経過 00:05:21] 【10回目】Type4: Fastpass`
